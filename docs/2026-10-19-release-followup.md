# 10/18 상호 테스트 후속 작업 (10/19 갱신)

## 확인된 결과

- 운영 API: 팀원 영상 4개 × 연사 선택/미선택 = 8건 분석 완료.
- 인증, 이력, 성장, 집중도, 설문 CSV, PDF, 슬라이드 변환, 게시판 기능/API 검사 34건 통과.
- 기존 점수: 혜정 76, 채현 45, 민서 72, 보현 64. 얼굴 인식 보완 전 결과이므로 발표용 최종 검증 수치로 재사용하지 않는다.
- UI 리뉴얼을 수정 브랜치에 통합. 운영 배포 여부는 별도 확인한다.
- 홈 점수 설명을 AHP v2와 일치시킴. 성장 그래프에 음성 추가.
- lint 6건 수정. 업로드 제한은 프록시 여유를 고려해 95MiB로 안내/검증.
- 호환 범위 내 의존성 보안 업데이트 완료. npm audit 전체 검사 취약점 0건.
- 얼굴 미검출 시 얼굴 검출 상자 확대 및 중앙 크롭 재시도 추가.
- 원본 영상별 20%, 50%, 80% 지점 표본 검사: 혜정 0/3→3/3, 채현 3/3→3/3, 보현 0/3→3/3, 민서 3/3→3/3.
- 표본 인식 개선은 전체 영상 정확도 검증과 구분한다. 배포 후 8건 재분석 필요.

## 남은 검증

- 배포 후 실제 카메라·마이크 권한, 녹화, 키보드/손동작 슬라이드 이동, 업로드부터 결과·이력까지 확인.
- 결과 탭 5개, 모바일 표시, 콘솔 오류, 인쇄 확인.
- 얼굴 보완 후 전체 영상의 얼굴 검출률·시선/표정 안정성 확인. 크롭은 얼굴 크기 보완이며 심한 각도는 촬영 제약으로 남을 수 있다.
- PDF는 기존 요약 리포트이며 모든 상세 탭을 포함하지 않는다. 상세 확장은 후속 범위로 관리.
- 제스처 임계값은 잠정 기준. 발표 자료에 보편적/검증 완료 기준으로 표현하지 않는다.

## 10/19 추가 기능 검증

- 전용 테스트 계정 회원가입 201 → 자동 발급 토큰으로 본인 조회 → 로그인 성공.
- 비밀번호 변경 200 → 이전 비밀번호 로그인 401 → 새 비밀번호 로그인 및 본인 조회 성공.
- 기존 실제 분석 결과 4종의 운영 PDF 다운로드 및 렌더링 확인. AHP 가중치·음성·별도 시간 점수 확인.
- PDF 검수에서 발견한 표지 줄 겹침 수정. 제스처 원시 횟수의 임의 판정 대신 저장된 분당 빈도와 실제 점수 상태를 표시.
- 1학기 양식 선호를 반영해 결과 요약을 좁은 단일 읽기 흐름으로 정리. 중복 핵심 진단은 접고, 실제 PDF 다운로드와 현재 탭 인쇄를 구분.
- AI 코칭은 PDF 3쪽에 먼저 배치하고 근거 이미지는 부록으로 분리해 마지막 우선순위만 다음 장으로 밀리는 현상 개선.
- 배포 Linux에서도 NanumGothic 폰트를 내장하도록 선택 경로 추가.
- 결과 이력에서 분당 제스처가 표시되지 않던 연결 누락 수정(details.summary fallback).
- 별도 Chromium + 운영 API: 데스크톱 주요 화면 6개, 결과 탭 5개, 모바일 390px 주요 화면 6개 가로 넘침 검사 통과. 처리되지 않은 JavaScript 오류 없음.
- 가상 카메라·마이크의 live 스트림과 실제 MediaRecorder 동작, 방향키·이전/다음 버튼 확인. 녹화 종료 후 운영 API 업로드 200 확인.
- 자동화의 가상 장치는 실제 노트북 카메라 화질·마이크 음질·실제 손동작 인식 검증을 대체하지 않는다.

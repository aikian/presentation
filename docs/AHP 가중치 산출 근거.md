# PresentationCoach AHP v2 가중치 산정 근거

## 1. 목적

기존 종합점수는 시선 30%, 자세 25%, 제스처 15%, 시간 30%로 구성되어 있었다.

그러나 목표 시간을 설정하지 않아도 시간 점수 80점이 부여되는 문제가 있었고, 새로 추가된 음성 분석 결과도 종합점수에 반영할 필요가 있었다.

이에 따라 발표평가 관련 문헌과 평가도구를 참고하여 시선·자세·제스처·음성의 가중치를 AHP 방식으로 다시 산정하였다.

---

## 2. 평가요소

| 평가요소 | 평가 내용                   |
| ---- | ----------------------- |
| 시선   | 발표 중 청중 또는 카메라를 바라보는 정도 |
| 자세   | 어깨 기울기와 신체 방향 등 자세의 안정성 |
| 제스처  | 발표 중 손동작을 사용하는 정도       |
| 음성   | 군말과 단조로움 등 음성 전달의 적절성   |

시간은 발표 전달 역량과 성격이 다른 보조 지표로 판단하여 AHP 평가요소에서 제외하였다.

---

## 3. 참고문헌 및 평가도구

### 3.1 핵심 참고문헌

| 문헌            | 확인한 내용                                           | 활용                     |
| ------------- | ------------------------------------------------ | ---------------------- |
| 강숙희(2016)     | 발표평가 항목의 중요도 평균이 음성 4.53, 시선 4.19, 제스처 3.69로 나타남 | 음성·시선·제스처의 상대적 우선순위 판단 |
| 변정민(2009)     | 성량, 속도, 시선, 자세, 몸짓 등이 발표자 평가에 관여함                | 자세 요소의 필요성 보완          |
| 이유나·허경호(2008) | 시각적 요소와 음성적 요소가 발표자 평가와 메시지 인지에 영향을 줌            | 시각 행동과 음성을 함께 평가하는 근거  |

강숙희(2016)의 결과에서는 다음과 같은 중요도 방향을 확인할 수 있다.

```text
음성(4.53) > 시선(4.19) > 제스처(3.69)
```

다만 위 수치는 5점 리커트 척도의 평균이므로, 평균값을 그대로 AHP 비율로 변환하지 않고 우선순위 방향을 판단하는 데 사용하였다.

### 3.2 평가요소 구성 자료

| 자료                                                                                                  | 확인한 내용                               | 활용                          |
| --------------------------------------------------------------------------------------------------- | ------------------------------------ | --------------------------- |
| 이연주·임경수(2020)                                                                                       | 음성, 시선, 제스처 등을 프레젠테이션 진단문항으로 구성함     | 국내 발표평가 요소의 구성 근거           |
| NCA                       | 발표의 음성 전달과 비언어적 전달 행동을 평가함           | 발표평가 도구에서 전달 행동을 평가한다는 근거   |
| Sümer et al.(2021) | 음성, 얼굴·시선, 신체 자세 특징을 이용하여 발표 역량을 추정함 | 여러 분석영역을 함께 활용할 수 있다는 보완 근거 |

## 4. 쌍대비교 판단

| 쌍대비교     | 판단        | 입력값 | 근거                               |
| -------- | --------- | --: | -------------------------------- |
| 시선 ↔ 자세  | 시선이 약간 중요 |   2 | 직접 비교 근거가 부족하여 약한 우세 적용          |
| 시선 ↔ 제스처 | 시선이 중요    |   3 | 강숙희(2016)에서 시선 중요도가 더 높게 나타남     |
| 시선 ↔ 음성  | 동등        |   1 | 음성이 조금 높지만 차이가 크지 않음             |
| 자세 ↔ 제스처 | 자세가 약간 중요 |   2 | 자세의 필요성을 반영하되 약한 우세 적용           |
| 자세 ↔ 음성  | 음성이 약간 중요 | 1/2 | 음성의 근거가 상대적으로 강하지만 직접 비교 근거는 부족함 |
| 제스처 ↔ 음성 | 음성이 중요    | 1/3 | 강숙희(2016)에서 음성 중요도가 더 높게 나타남     |

쌍대비교행렬은 다음과 같다.

| 평가요소 |  시선 |  자세 | 제스처 |  음성 |
| ---- | --: | --: | --: | --: |
| 시선   |   1 |   2 |   3 |   1 |
| 자세   | 1/2 |   1 |   2 | 1/2 |
| 제스처  | 1/3 | 1/2 |   1 | 1/3 |
| 음성   |   1 |   2 |   3 |   1 |

## 5. 최종 가중치

| 평가요소 |     가중치 |
| ---- | ------: |
| 시선   |  35.12% |
| 자세   |  18.87% |
| 제스처  |  10.89% |
| 음성   |  35.12% |
| 합계   | 100.00% |

일관성 비율은 `CR = 0.0038`로, 일반적인 허용 기준인 `0.10`보다 낮아 쌍대비교 판단의 일관성을 충족한다.

시선과 음성의 우세 방향을 변경하는 민감도 분석에서도 자세와 제스처의 가중치는 거의 변하지 않았다. 따라서 현재는 시선과 음성을 동등하게 설정한 결과를 기준안으로 사용한다.

## 6. 점수 처리 정책

### 분석 불가 항목

분석할 수 없는 평가요소는 `0`이 아닌 `None`으로 처리한다.

* `0`: 분석 결과가 실제 최저점인 경우
* `None`: 데이터가 없거나 분석할 수 없는 경우

`None`인 항목은 종합점수 계산에서 제외하고, 분석된 항목의 가중치만 재정규화한다. 모든 평가요소가 `None`이면 종합점수도 `None`으로 반환한다.

### 시간 점수

시간 점수는 다음과 같이 처리한다.

* 종합점수와 AHP 가중치에서 제외한다.
* 목표 시간을 설정한 경우에만 계산한다.
* 목표 시간이 없으면 `score_time`을 `None`으로 처리한다.
* 계산된 시간 점수는 별도의 피드백으로 제공한다.

## 7. 코드 적용 시 확인사항

* AHP v2 가중치를 종합점수 계산에 적용한다.
* 음성 점수를 종합점수에 포함한다.
* 시간 점수는 종합점수에서 제외한다.
* 분석 불가 항목의 `None` 처리와 가중치 재정규화를 유지한다.
* 프론트엔드와 데이터베이스에서 `null` 값을 정상적으로 처리하는지 확인한다.

---

## 8. 한계 및 추후 검토

현재 가중치는 전문가 대상 AHP 설문으로 산출한 결과가 아니라, 발표평가 문헌과 평가도구를 참고하여 쌍대비교값을 설정한 결과이다.

특히 자세가 포함된 비교는 직접적인 근거가 부족하여 문헌과 팀 판단을 함께 반영하였다. 따라서 현재 가중치는 프로젝트의 초기 점수 기준으로 사용하고, 추후 발표 영상 테스트와 사용자 피드백이 축적되면 다시 조정할 수 있다.
